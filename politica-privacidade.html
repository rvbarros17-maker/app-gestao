Política de Privacidade

Totaliz - Sistema de Gestão Empresarial

Última atualização: Janeiro de 2026

1. Introdução

A presente Política de Privacidade descreve como o Totaliz, operado por Rafael Victor de Barros, CPF 079.180.569-73, com endereço na Rua Pioneiro Abílio Gaspar, 306, Maringá/PR, CEP 87025-828, coleta, usa, armazena e protege as informações pessoais dos usuários.

Esta política está em conformidade com a Lei Geral de Proteção de Dados (LGPD - Lei nº 13.709/2018) e o Marco Civil da Internet (Lei nº 12.965/2014).

2. Definições

  • Usuário/Cliente: Pessoa física ou jurídica que utiliza o Totaliz
  • Dados Pessoais: Informações relacionadas a pessoa identificada ou identificável
  • Tratamento de Dados: Coleta, armazenamento, uso, processamento e exclusão de dados
  • Controlador: Rafael Victor de Barros (responsável pelas decisões sobre tratamento de dados)
  • Operador: Firebase/Google Cloud (processa dados em nome do Controlador)

3. Dados Coletados

3.1. Dados Fornecidos pelo Usuário

  • Cadastro: Nome, e-mail, senha (criptografada)
  • Empresa: Nome da empresa, logo (opcional)
  • Dados Empresariais: Clientes, produtos, vendas, movimentações financeiras, receitas, despesas

3.2. Dados Coletados Automaticamente

  • Dados de Acesso: Endereço IP, navegador, sistema operacional, data/hora de acesso
  • Dados de Uso: Funcionalidades utilizadas, tempo de sessão, páginas visitadas

3.3. Dados de Pagamento

Os dados de pagamento (cartão de crédito, Pix) são processados exclusivamente pelo Stripe e não são armazenados nos servidores do Totaliz.

4. Finalidade do Tratamento de Dados

Os dados coletados são utilizados para:

  • Criar e gerenciar conta do usuário
  • Fornecer acesso ao sistema Totaliz
  • Processar pagamentos e gerenciar assinaturas
  • Prestar suporte técnico via WhatsApp/e-mail
  • Melhorar funcionalidades do sistema
  • Enviar notificações importantes sobre o serviço
  • Cumprir obrigações legais e regulatórias
  • Prevenir fraudes e garantir segurança

5. Base Legal (LGPD)

O tratamento de dados pessoais é fundamentado em:

  • Execução de Contrato (Art. 7º, V): Prestação do serviço Totaliz
  • Consentimento (Art. 7º, I): Aceite dos Termos de Uso e Política de Privacidade
  • Legítimo Interesse (Art. 7º, IX): Melhorias no sistema e suporte técnico
  • Cumprimento de Obrigação Legal (Art. 7º, II): Legislação tributária e contábil

6. Compartilhamento de Dados

Seus dados podem ser compartilhados com:

6.1. Prestadores de Serviço

  • Firebase/Google Cloud: Armazenamento e hospedagem de dados
  • Stripe: Processamento de pagamentos
  • Vercel: Hospedagem da aplicação web

6.2. Autoridades Legais

Podemos compartilhar dados quando exigido por lei, ordem judicial ou autoridades competentes.

6.3. Não Vendemos Dados

Nunca vendemos, alugamos ou comercializamos seus dados pessoais para terceiros.

7. Armazenamento e Segurança

7.1. Local de Armazenamento

Todos os dados são armazenados em servidores seguros do Firebase (Google Cloud), localizados em data centers certificados internacionalmente.

7.2. Medidas de Segurança

  • Criptografia de dados em trânsito (HTTPS/TLS)
  • Senhas criptografadas com hash seguro
  • Autenticação via Firebase Authentication
  • Backups automáticos diários
  • Controle de acesso baseado em permissões
  • Monitoramento de segurança 24/7

7.3. Período de Retenção

Os dados são mantidos enquanto a conta estiver ativa. Após cancelamento da assinatura, os dados são mantidos por até 90 dias para possível reativação, sendo completamente excluídos após esse período, salvo obrigação legal de guarda.

8. Direitos do Titular (LGPD - Art. 18)

Você tem direito a:

  • Confirmação: Saber se tratamos seus dados
  • Acesso: Visualizar seus dados pessoais
  • Correção: Corrigir dados incompletos ou desatualizados
  • Anonimização/Bloqueio: Solicitar anonimização ou bloqueio
  • Eliminação: Excluir dados desnecessários ou tratados indevidamente
  • Portabilidade: Exportar seus dados em formato estruturado
  • Revogação do Consentimento: Retirar consentimento a qualquer momento
  • Oposição: Opor-se ao tratamento em situações específicas

Para exercer seus direitos, entre em contato: contato@totaliz.com.br ou WhatsApp (44) 99152-2243

9. Cookies e Tecnologias Similares

O Totaliz utiliza cookies essenciais para funcionamento do sistema (autenticação, sessão). Não utilizamos cookies de terceiros para rastreamento ou publicidade.

Você pode desabilitar cookies nas configurações do navegador, mas isso pode afetar o funcionamento do sistema.

10. Menores de Idade

O Totaliz é destinado a maiores de 18 anos. Não coletamos intencionalmente dados de menores. Caso identifiquemos dados de menores, serão excluídos imediatamente.

11. Alterações nesta Política

Esta Política pode ser atualizada periodicamente. Alterações significativas serão comunicadas por e-mail ou notificação no sistema. A versão atualizada sempre estará disponível no site.

12. Legislação e Foro

Esta Política é regida pelas leis brasileiras, especialmente a LGPD (Lei 13.709/2018). Fica eleito o foro da Comarca de Maringá/PR para dirimir quaisquer controvérsias.
